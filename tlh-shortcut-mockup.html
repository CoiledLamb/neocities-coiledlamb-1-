What to try: courier is walking the ring clockwise. Hover any node to see distance via ring vs. via shortcut. Click a non-adjacent node → courier cuts the interior on a gentle bezier curve. A dotted cyan trail traces behind, each cell fading as it ages. On arrival, the courier resumes ring clockwise from that node. Click another target mid-transit to replan from the courier's current position.

Natural curve: quadratic bezier with one control point offset perpendicular to the straight line by ~15% of segment length. Deterministic bow direction based on endpoint hash so re-running the same shortcut follows the same curve.

Trail fade: each cell has an age counter, opacity = max(0, 1 - age/FADE_TICKS). Fade window here = 300 ticks (~1.7s at the 4× mockup speed; would be ~105s at live 350ms/tick). Session-only — persistent multiplayer-synced trails land in v0.0.9.6 with the world-overlay system.

Adjacent-click rejection: clicking the next or previous ring neighbor does nothing (they're already on the ring path). Tooltip shows "adjacent" instead of a shortcut option.

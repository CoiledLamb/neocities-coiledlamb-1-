Persistent trample visual — comparing two approaches against the current implementation.

Option A — persistent dots, scales with trample

Trample is a separate dot layer. Opacity = trample * 0.75. Courier's live fade-trail keeps its own behavior — same cyan, just time-based.

What you see: Persistent cyan dots at every trampled cell. Dense in the mountain pass (heavily carved, bright), lighter on the spur (recently walked, faint). Rocky hills show a busy area still building up. Courier's fade-trail uses the same dot visual but disappears over ~8s.
Tradeoff: Simple rule, easy to read. But there's no visual distinction between "I walked here" vs "peer walked here" vs "I'm walking here now" — they all merge into one cyan dot layer.

Option B — trail dots fade to a trample floor

Single mechanic. Courier drops trail dots as usual; instead of fading to zero, each dot's opacity floors at trample[cell]. No separate overlay layer.

What you see: Same cyan dots as A in the mountain area — but these are literally the courier's own trail dots that faded to their trample-floor instead of to zero. Heavy path cells look near-identical to A. Low-trample cells nearly-but-not-fully-faded. Rocky hills (peer-tramped but unvisited-by-me) render nothing.
Tradeoff: Unifies mechanisms: one dot system, one trail logic. But peer trample is invisible until you visit. For a solo player that's fine; for the multiplayer “someone paved a pass” moment to land, Option A is stronger.

Quick comparison

  • Option A — separate persistent-dot layer. Peer trample shows up. Heavy visual consistency between "live trail" and "persistent trample." Two data sources (live trailCells + trample map) collapsed into one visual language.
  • Option B — trail dots floor at trample. One mechanic, one layer. Peer trample is invisible until visited — so the multiplayer "paved it for you" feel is muted. Better for a solo feel.
  • Both drop the , / ; / : glyph-swap, which was the main busy-ness complaint.
  • Both use the existing cyan #77bfcf — no new palette.
  • Visibility floor: I've shown both with "any trample > 0 shows, just very faint" per your “walking anywhere should leave a path” call. Paving still takes real effort in either approach — it's the opacity that differentiates.
